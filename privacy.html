Privacy Policy

Last updated: 26 November 2026

"What Is This Shorts" (the "tool") is a private publishing tool used only by the owner of the YouTube channel "Pip: What Is This?". This policy explains what data the tool uses and how.

Who uses the tool

Only the channel owner. The tool runs on the owner's own computer. It is not a public service and has no other users.

Data the tool accesses

When the owner signs in with Google and allows access, the tool can, for the owner's own channel only:

  • upload videos and set their title, description, tags, publish time, captions and thumbnail;
  • read the channel's basic details and its list of uploaded videos (to avoid uploading the same video twice);
  • read the channel's YouTube Analytics reports (views and similar statistics).

The tool does not access any other person's account, comments, messages, contacts or personal information.

How the data is used and stored

  • The data is used only to publish the owner's videos and to show the owner how the videos perform.
  • The Google sign-in key is stored only on the owner's computer. Video statistics are stored there too.
  • No data is sold, shared with third parties, or used for advertising.

The tool's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube API Services

The tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Removing access and data

Access can be removed at any time at myaccount.google.com/permissions or Google security settings. Deleting the tool's folder from the owner's computer deletes all data it stored.
